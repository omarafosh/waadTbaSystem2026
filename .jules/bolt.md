## 2026-03-28 - [Targeted JPQL Enum Filtering for Pre-Authorizations]
**Learning:** When using Spring Data JPA, mapping Enums inside JPQL queries as string literals (`AND pa.status = 'APPROVED'`) is a dangerous anti-pattern that can cause application crashes at startup due to strict type validation in modern Hibernate versions (`IllegalArgumentException` or `SemanticException`).
**Action:** Always bind Enums via named parameters (e.g., `AND pa.status = :status`) and pass the fully qualified or imported Enum from the Service/Repository call (e.g., `@Param("status") PreAuthStatus status`). Additionally, when attempting to resolve in-memory filter loops (e.g., `repository.findAll().stream().filter(...)`), moving most attributes to JPQL but keeping complex date/time or custom business logic checks (`pa.isExpired()`) in Java safely reduces the dataset size while avoiding SQL/Java discrepancy bugs.
