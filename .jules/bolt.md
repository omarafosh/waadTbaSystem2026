## 2026-04-27 - Replace N+1 and full table loads in RoleManagementService
**Learning:** In the RBAC module, the JPA relationship between User and Role is unidirectional from User (via User.roles); Role does not have a mapped users collection. JPQL queries joining users and roles must therefore drive from the User entity (e.g., `SELECT r.id, COUNT(u) FROM User u JOIN u.roles r`).
**Action:** When checking relationship counts or mapping sub-fields (like fetching usernames by a specific role), avoid fetching full entity lists with `findAll().stream().map(...)` as it causes unnecessary memory consumption. Instead, use targeted JPQL `@Query` methods (e.g., `countByRolesId`, `findUsernamesByRolesId`) directly in the `UserRepository` to push projection and aggregate counting directly to the database.
