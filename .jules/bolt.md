## 2026-06-29 - JPQL Enum String Literals vs. Parameter Binding
**Learning:** In the existing `PreAuthorizationRepository`, enums like `PreAuthStatus` are queried using hardcoded string literals (e.g., `pa.status = 'APPROVED'`). While parameter binding (e.g., `@Param("status")`) is generally preferred for strict type safety and to avoid parser issues depending on the JPA/Hibernate configuration, matching the existing string literal pattern works seamlessly in this codebase and avoids parsing/casting exceptions without extra refactoring.
**Action:** When adding new `@Query` methods that filter by Enums, check existing repository methods. If they use string literals (e.g., `'APPROVED'`), it is safe and often simpler to mimic that pattern unless there is a specific need to refactor for strict type safety.
