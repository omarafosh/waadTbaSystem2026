## 2026-05-24 - Avoid `UnnecessaryStubbingException` in Isolated Maven Tests
**Learning:** When running isolated unit tests using `mvn -Dtest=... test`, context-dependent tests (like `UnifiedMemberServiceTest`) often fail because Mockito requires strict stubbing validation by default. Attempting to manually add mock properties and `lenient().when(...)` statements inside the test methods is brittle and prone to cascading compilation errors due to missing imports or method signatures.
**Action:** Instead of manually injecting `lenient()` stubs, globally relax Mockito validation for the test class by adding the `@org.mockito.junit.jupiter.MockitoSettings(strictness = org.mockito.quality.Strictness.LENIENT)` annotation at the class level. This cleanly resolves the `UnnecessaryStubbingException` without cluttering the test implementation with unnecessary boilerplate.
