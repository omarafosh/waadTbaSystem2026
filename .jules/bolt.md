## 2026-04-16 - N+1 Queries in User and Role Repository `findAll` Methods
**Learning:** Despite previous assumptions in memory stating that N+1 queries were resolved in `UserService` and `RoleService` via targeted counts or mapping, full-table `findAll().stream()` loops were still present. These methods lacked `LEFT JOIN FETCH` directives to properly load relationships (like `roles` for `User` and `permissions` for `Role`).
**Action:** When inspecting services mapping entities with lazy-loaded relationships inside a `stream().map(...)`, do not rely solely on memory notes claiming the bottleneck is "resolved." Always check the source query backing the `findAll()` operation and implement a `SELECT DISTINCT e FROM Entity e LEFT JOIN FETCH e.relationship` method if a full scan is required for mapping.
