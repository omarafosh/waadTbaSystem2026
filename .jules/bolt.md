## 2026-04-17 - [Optimized checkValidity with Database Filtering]
**Learning:** In Spring Boot services, filtering large datasets using `repository.findAll().stream().filter(...)` causes severe full-table scans and high memory consumption. Converting these to targeted parameterized JPQL queries pushes the logic to the database and correctly mimics stream comparisons (e.g. enum matching, null checks) safely and efficiently. Additionally, it is critical to verify isolated test compilation as `mvn -DskipTests` misses failing mocked dependencies like `UnnecessaryStubbingException` when fixing related test suites under strict Mockito rules.
**Action:** Always replace `findAll().stream()` with a parameterized JPQL query for database-level filtering. Always use `mvn -Dtest=ClassNameTest test` to verify localized tests pass and use `org.mockito.Mockito.lenient().when(...)` to bypass strict mockito exceptions if test dependencies are missing.
